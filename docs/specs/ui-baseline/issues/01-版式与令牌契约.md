# 01 把 LeptonX 版式与令牌钉成契约

- 状态：`done`（2026-10-26；全量 228 单元 + 192 集成绿，0 警告）
- Blocked by：无
- 缝：真实 HTTP 管道渲染出的后台页面 HTML + 站点内静态资源内容（已与用户确认）

## 交付什么

一条能拦住"度量与令牌再次漂移"的契约测试，并顺带修掉一条与新基线冲突的既有断言。
票的小，但完整：从静态资源内容、布局结构到全量测试通过，单独可验证。

## 现状

- 视觉改动已落地：280px 深色侧栏、36px 直角菜单项、64px 顶栏（深色壳 + 浅色浮条）、
  内容区 42/28/56、无描边白卡、主色 `#355dff`。
- **既有"协议页与后台共用同一份设计令牌"用例仍断言 `--ah-primary: #4f46e5`，当前为红。**
  本票的第一个红→绿循环就是它——这不是新行为，是旧断言没跟上已签字的品牌决策。

## 验收条件

## 不在本票范围

- 不改任何视觉取值，不改登录页版式，不引入浏览器驱动或截图 diff 进 CI。

## 为什么断言静态资源内容而不是像素

缝只有一条，且它看不到计算样式。度量以"样式表里的声明 + 令牌值"为契约（改一个值就会被抓到），
真实像素留在发布验证阶段用固定视口实测——这是开发规格里写明的分工。
