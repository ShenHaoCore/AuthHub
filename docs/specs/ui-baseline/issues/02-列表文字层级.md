## 交付什么

六个列表页与个人页共用同一套三档文字层级，并把"等宽只换字族、不换字号"这条规则钉住。
交付后，跨页切列表不再出现正文 12.5px 与 14px 混用、行高 20px 与 22.4px 摆动。

- 根因是等宽类自带 12.5px 字号，且被直接用在单元格与主行上；已修为只换字族。
- 仪表盘"用户"列此前用普通正文，比其它列表的主行轻一档；已改用主行层级。
- 本票不给已成型的样式补新功能，只把上述契约写成测试并修掉测试暴露的偏差。
