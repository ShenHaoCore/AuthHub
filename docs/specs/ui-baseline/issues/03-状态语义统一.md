# 03 状态语义与用词统一

- 状态：`done`（2026-10-26；全量 228 单元 + 192 集成绿）
- Blocked by：02（同为一个测试类，串行领取；分类与计数的写法已在 02 的层级上定型）
- 缝：真实 HTTP 管道渲染出的后台页面 HTML

## 交付什么

一张可执行的"语义 → 色调/措辞"对照表：绿＝正常/已完成，琥珀＝待处理/有风险，红＝不可用/失败，
灰＝分类/计数/非状态说明，蓝只给身份标签。交付后，同一含义在不同页面不会换色、换词、换载体。

## 现状

- 已修正：用户页 MFA 由"蓝徽章 + 灰字"改为"绿 已开启 / 琥珀 未开启"；资源"已停用"由琥珀改红；
  客户端"已禁用"改为"已停用"；客户端类型与"协议"标记去蓝；引用数与权限点计数回归正文/灰字；
  审计"启用两步验证"由蓝改绿。
- 本票把这些修正写成跨页参数化断言，并清掉残留的 `info` 色调。
